# Contributing

Bug reports and focused pull requests are welcome.

For a bug report, include the headset, OpenXR runtime, GPU, exact reproduction
steps, save/chapter, and `outlast2_vr_p34.log`. Do not attach saves, game files,
extracted assets, or the Outlast 2 executable.

For a pull request, include:

- the internal build ID tested;
- why the change is necessary;
- the source files changed;
- automated test results;
- headset and runtime used;
- checks of menus, gameplay, scripted scenes, camcorder, interactions, and save
  loading;
- known limitations or regressions.

Keep unrelated refactors separate from renderer, camera, or input changes.
